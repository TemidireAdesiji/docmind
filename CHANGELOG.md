## [1.0.0] - 2026-03-30

### Added

- Hierarchical parent/child document splitting with configurable bounds.
- Hybrid (dense + sparse) vector search via Qdrant.
- Two-tier LangGraph reasoning pipeline with parallel fan-out.
- Query clarity assessment with human-in-the-loop clarification.
- Context compression for long conversations.
- PDF and Markdown ingestion with automatic conversion.
- Streaming Gradio web interface with dark theme.
- File-backed JSON store for parent segments.
- Optional Langfuse tracing.
- Pydantic-based settings with env var configuration.
- Structured logging via loguru.
- Docker deployment with automatic model pulling.
- 63-test suite covering core logic.
- Full documentation suite.
